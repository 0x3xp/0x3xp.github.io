01 / About

I am a security researcher and red team operator focused on endpoint security and low-level Windows research. My work spans reverse engineering, malware development, offensive tool engineering, and penetration testing. I am the founder and security researcher at Manifold Operations, a security research and development company building offensive tooling, conducting adversary simulation, and advancing original research.

My primary specialization is AV/EDR evasion — understanding how endpoint products observe Windows, where telemetry originates, and how execution techniques affect what a security product can detect. This work spans syscall research, Windows internals, kernel-mode execution, binary analysis, and adversary emulation.

I approach security work from the implementation level: understand the operating system, inspect binary behavior, build the proof of concept, test the result, and document the defensive implications. I also contribute to open source security-relevant projects upstream — finding and fixing real bugs in production networking and systems libraries used across major infrastructure.

01 / About

I am a security researcher and red team operator focused on endpoint security and low-level Windows research. My work spans reverse engineering, malware development, offensive tool engineering, research and development, and penetration testing.

My primary specialization is AV/EDR evasion. I study how endpoint products observe Windows, where telemetry is generated, and how execution techniques change what a security product can see. This work includes syscall research, Windows internals, kernel research, binary analysis and adversary emulation.

I approach security work from the implementation level: understand the operating system, inspect the binary behavior, build the proof of concept, test the result, and document the defensive implications. My public work is centered on authorized research and controlled environments.

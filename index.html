01 About

I work at the intersection of offensive security, operating system internals, and endpoint detection.

My primary discipline is AV/EDR evasion. I study the points where security products instrument Windows, how telemetry is generated, and how changes in execution, memory access, and operating-system interaction affect what defenders can observe.

My broader work covers red team operations, reverse engineering, malware development, research and development, and penetration testing. I build and analyze software rather than treating security tooling as a black box.

Current research interests include Windows internals, native APIs, system call behavior, PE structures, kernel execution, process and memory internals, and defensive visibility at the endpoint.

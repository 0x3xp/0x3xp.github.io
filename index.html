Libslirp: ICMP Echo Reply Length Desynchronization Leaks Host IP to Guest

Oct 2026
Official Acknowledgement

"Red Hat would like to thank Piyusha Akash for reporting this issue."

Red Hat Product Security Advisory · Bugzilla RHBZ#2558916

A vulnerability was discovered in libslirp, the user-mode networking stack underpinning QEMU, VirtualBox, and virtualization hypervisors across enterprise infrastructure. When handling ICMP echo requests under conditions where the standard ICMP socket is unavailable, the reply packet length is not updated to match the actual data received from the host network stack.

This length mismatch causes uninitialized packet buffer slices containing the host's physical IP address to be returned in the echo reply to the guest virtual machine, breaking user-mode NAT isolation and exposing the host's actual IP to unprivileged guest environments.

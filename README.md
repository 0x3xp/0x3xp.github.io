# 0x3xp Portfolio

Static GitHub Pages portfolio for Piyusha Akash.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

No Jekyll, framework, package manager, or build step is required.

## Pages

- `index.html` profile and professional biography
- `projects/projects.html` projects and research work
- `blog/blog.html` technical writing

## Editing content

Portfolio content is kept in the HTML source so it can be edited directly without a CMS or build system.

## JavaScript

The `main/` directory contains only browser behavior and the small shared year renderer. Visible portfolio content is not generated by JavaScript.

Featured research 01

Windows Kernel Research

Lethe

A Windows kernel-mode research tool built around a self-rescheduling KTIMER, KDPC, and IO_WORKITEM execution chain. The project investigates kernel execution, process and memory internals, credential-access paths, token manipulation, and endpoint detection surfaces.

GitHub ↗ Technical Wiki ↗
LanguageC
PlatformWindows x64
Kernel pathKTIMER → KDPC → IO_WORKITEM
Research areasKernel execution · EPROCESS · detection surface
DocumentationREADME · Wiki · BYOVD notes
Execution model

The DPC performs minimal scheduling work before the system worker queue executes the main logic at PASSIVE_LEVEL.

Defensive perspective

The research explicitly documents what user-mode tools can and cannot observe, while noting kernel and hypervisor monitoring limits.

Research status

Built for controlled security research and red team testing. The project documentation records limitations rather than claiming absolute invisibility.

Lethe

Lethe is a Windows kernel-mode research and red team tool centered on a KTIMER, KDPC and IO_WORKITEM execution chain. The project investigates kernel execution, process and token structures, endpoint visibility, driver loading constraints and the defensive boundaries around kernel activity.

Research scope

The project documentation also records limitations and defensive surfaces, including kernel telemetry, direct memory inspection, HVCI, driver blocklists and protected process constraints.

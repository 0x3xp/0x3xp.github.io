Windows kernel research

Lethe

A Windows kernel-mode research project focused on alternative kernel execution paths and the defensive visibility around them.

Lethe explores a self-rescheduling execution chain using KTIMER, KDPC, and IO_WORKITEM, providing a practical environment for studying kernel execution, process and memory internals, token operations, credential-access research, and endpoint detection surfaces.

Architecture

Scheduling work begins through a timer and DPC path before the main logic is dispatched through a system worker queue at PASSIVE_LEVEL.

Research value

The project creates a concrete environment for studying how kernel execution changes the telemetry available to endpoint defenses.

Defensive view

The documentation includes limitations and monitoring considerations instead of relying on absolute claims about invisibility.

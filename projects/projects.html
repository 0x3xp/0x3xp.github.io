Featured project01

Windows Kernel Research

Lethe

Lethe is a Windows kernel-mode research project exploring an alternative execution path built around a self-rescheduling KTIMER, KDPC, and IO_WORKITEM chain. The project uses that architecture to investigate kernel execution, process and memory internals, token operations, credential-access paths, and endpoint detection surfaces.

LanguageC
PlatformWindows x64
ExecutionKTIMER → KDPC → IO_WORKITEM

Architecture

The DPC path performs scheduling work before the main logic is dispatched through the system worker queue at PASSIVE_LEVEL.

Research value

The project provides a practical environment for studying Windows kernel execution and the boundary between user-mode visibility and deeper telemetry.

Defensive view

The project documentation describes limitations and monitoring considerations instead of making absolute claims about invisibility.

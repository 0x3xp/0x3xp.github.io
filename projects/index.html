Lethe

Lethe is a Windows kernel-mode research and red team tool centered on a KTIMER, KDPC, and IO_WORKITEM execution chain. The project investigates kernel-mode execution, process and token structures, driver visibility and loading constraints, endpoint detection surfaces, and the defensive boundaries around kernel-level activity.

Research scope

Project documentation records technical findings alongside limitations and defensive surfaces, including kernel telemetry, direct memory inspection, HVCI, driver blocklists, and protected process constraints. Built with C and the Windows Driver Development Kit.
